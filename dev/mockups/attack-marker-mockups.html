Marcador de “está atacando” — alternativas al galón naranja

Hoy el marcador es .battlefield-card-slot::after (galón doble naranja + halo ::before), encendido por .host-attacker-readied en Battlefield.tsx. Cada bloque muestra la misma fila de campo: Soldado y Sabueso atacando, Titán quieto, para ver el contraste entre “ataca” y “no ataca”. Las cartas son el recorte real de campo (viewport 488×434 con el battlefieldArtFrame de cada carta), así se ve cómo convive cada marcador con el arte, el nombre y la placa de stats.

Todo es CSS puro sobre el slot: nada depende de medir posiciones.
